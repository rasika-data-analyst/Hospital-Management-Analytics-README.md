# Hospital Management Analytics — Project Workflow

## Project Objective
Analyze hospital operations, appointments, billing, patient activity, and admissions using SQL, Python, and Power BI.

## Tools Used
- SQL / MySQL
- Python and Pandas
- Microsoft Power BI and DAX
- GitHub

## Dashboard Pages
1. Executive Overview
2. Appointment Operations
3. Financial Performance
4. Patient & Admission Insights

## Workflow
1. Inspect source tables and data types.
2. Clean missing values and investigate duplicates.
3. Validate keys and relationships.
4. Analyze business metrics using SQL and Python.
5. Build Power BI measures and visualizations.
6. Test slicers, interactions, and KPI calculations.
7. Document data-quality limitations before publication.

## Data Privacy
Publish only synthetic, anonymized, or otherwise safe-to-share data. Do not upload identifiable patient records or credentials.

# Hospital Management Analytics — Python

## Project Overview
This project uses Python and Pandas to explore hospital operations data, validate data quality, calculate key metrics, and identify business patterns.

## Work Completed
- Data validation and profiling
- Missing-value and duplicate analysis
- Date and data-type checks
- Exploratory data analysis
- Hospital operations KPI calculations
- Business insights to support management decisions

## Tools
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Project Files
- `hospital management.ipynb` — hospital data analysis
- `data validation hospital management.ipynb` — data validation and quality checks


## Data Privacy
Only synthetic, anonymized, or approved data should be shared publicly. Do not publish identifiable patient information.
